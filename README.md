# Potato-Themed Pomodoro Timer
A browser based application design for productivity and focus for users using the Pomodoro technique.



## Features 
* Pomodoro Timer
* Ambient background noises:
  * Brown Noise
  * Green Noise
  * Pink Noise
  * White Noise
* Start, pause controls
* Task lisk: add, edit and delete tasks



## Technologies Used
* JavaScript
* HTML
* CSS
